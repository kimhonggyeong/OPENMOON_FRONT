# 견적서 저장소 설정

서버를 실행하고 사용자 선택을 마치면 **웹 열기** 옆에 **저장소 설정**이 표시됩니다. 게스트 화면에는 표시되지 않습니다.

1. NAS 기본 폴더의 전체 주소를 붙여넣거나 **폴더 찾아보기**로 선택합니다.
2. **연도 추가**를 누르고 연도를 입력한 다음 기본 폴더 안의 해당 연도 폴더를 선택합니다. 폴더 선택창에서 새 폴더를 만들 수도 있습니다.
3. **연결 확인**으로 읽기·쓰기 권한을 확인하고 **저장 후 적용**을 누릅니다.

예: 기본 폴더 `\\192.168.0.29\backup-1\1. 견적서`, 2026년 폴더 `@@26-견적서@@`.

폴더는 서버 PC를 기준으로 선택합니다. 접근이 안 되면 서버 PC의 탐색기에서 NAS에 로그인하고 권한을 확인하세요. 연결 확인은 고유한 임시 파일을 쓰고 읽은 뒤 삭제합니다.

새 견적 파일은 생성 연도 폴더에 저장됩니다. 등록된 연도 폴더와 그 하위 폴더에서 기존 견적을 찾으며, 올해 폴더의 결과를 먼저 표시합니다. 기존 파일을 선택하면 선택한 위치에 시트를 추가합니다. 연도 연결이 하나도 없으면 기본 폴더를 그대로 사용하는 기존 방식으로 동작합니다.

새해 폴더가 미등록이면 새 파일 생성을 막고 서버장에게 연도 추가를 안내합니다. 기존 견적 선택은 계속 가능합니다. 견적서 생성 중에는 저장소 설정 적용이 차단됩니다.

NAS 주소나 폴더 변경은 파일을 옮기지 않습니다. 필요한 자료를 새 위치에 먼저 복사하세요. 이전 경로 연결 정보를 보관해 기존 기록의 원본 열기와 다운로드에 사용합니다. 동일한 상대 경로를 유지하면 안정적으로 연결됩니다. 파일을 임의로 재분류한 경우 파일명이 유일할 때만 일부 원본 열기에서 검색으로 찾을 수 있으며, 같은 이름이 여러 개면 확인이 필요합니다.

설정은 EXE 옆 `backend/data/quotation_storage.json`에 저장되어 다시 실행해도 유지됩니다. 업데이트할 때 이 파일을 포함한 기존 `backend/data`와 `.env`를 보존하세요. 운영·검색 DB와 고객용 PDF 생성 위치는 기존 서버 PC 설정을 유지합니다.

서버 시작 시, 그리고 저장소 설정 적용 직후 지정된 연도 폴더에서 과거 견적 검색 DB를 자동 갱신합니다. 바뀌지 않은 파일은 다시 해석하지 않습니다. 서버장 화면에 진행률과 결과가 표시되며 설정창의 **과거 견적 갱신** 버튼으로 다시 실행할 수 있습니다. 새 DB를 임시 위치에서 완성·검증한 다음 반영하므로 연결 오류·파일 해석 오류가 나면 기존 검색 DB를 유지합니다. 실제 견적 파일이나 업무 DB를 초기화하지 않습니다.

과거 견적 목록의 표시 경로와 원본 열기는 현재 선택된 저장소를 기준으로 합니다. 이전 로컬 파일이 남아 있어도 대신 열지 않습니다. 동일 파일명이 여러 연도에 있고 이전 경로를 정확히 연결할 수 없으면 임의로 선택하지 않습니다.

파일 위치가 바뀌었더라도 기존 DB에 저장된 파일 크기·내용 해시가 일치하는 이전 파일이 하나로 확인되면, 견적과 품목 데이터를 재분석하지 않고 경로만 갱신합니다. 내용 확인을 위해 이동한 파일을 한 번 읽는 시간은 필요합니다. 기존 위치의 파일도 계속 선택 범위에 있거나 동일 내용의 이전 기록이 여러 개여서 대상을 특정할 수 없으면 별도 파일로 분석합니다. 수정 날짜만 바뀌고 내용이 같으면 날짜 정보만 갱신합니다. 변경이 전혀 없는 실행에서는 실제 검색 DB도 다시 쓰지 않습니다.
